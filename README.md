# محرر PDF المحلي — نسخة الويب وتطبيق أندرويد (v1.0.0)

تطبيق محلي لدمج وتعديل ملفات PDF **بخصوصية كاملة ودون الحاجة للإنترنت**، يعمل كتطبيق ويب (Next.js / Netlify Drop) وكتطبيق أندرويد أصلي (**APK** عبر Capacitor 6).

## أبرز الميزات
- **دمج وإدارة الصفحات:** رفع متعدد، ترتيب الملفات والصفحات، نطاقات صفحات (مع الأرقام العربية `١-٥، ٨`)، مصغّرات كسولة عبر `PDF.js`، تدوير وحذف واستعادة.
- **المحرر التفاعلي:** إضافة نصوص عربية وإنجليزية (تضمين خط `DejaVuSans` TTF متجه مع تشكيل و`BiDi`)، إضافة صور، ولوحة توقيع باللمس والماوس مع قص تلقائي وحفظ في الجلسة.
- **تكييف أندرويد الأصلي (Capacitor 6):**
  - خطوط عربية مضمّنة محلياً للعمل 100% دون إنترنت (`NotoSansArabic` + `DejaVuSans`).
  - حفظ ومشاركة الملف الناتج عبر `Filesystem` و`Share` و`FileProvider`.
  - استقبال ملفات PDF مباشرة عبر **«فتح بواسطة / مشاركة»** من واتساب ومدير الملفات.
  - دعم زر الرجوع الفيزيائي، شريط الحالة، وحدود ذاكرة متحفظة للهواتف (`100MB` و30 مصغّرة).
  - بناء `APK` تلقائي عبر GitHub Actions (`.github/workflows/android-apk.yml`) أو محلياً عبر Gradle.

## الأوامر السريعة

```bash
# التشغيل والتطوير على الويب
npm install
npm run dev

# فحص الأنواع + Lint + اختبارات Vitest + بناء الإنتاج
npm run verify

# بناء تطبيق أندرويد APK للاختبار محلياً (الناتج في dist-apk/pdf-studio-debug.apk)
npm run android:apk:debug

# إنشاء مفتاح التوقيع وبناء الإصدار النهائي الموقّع
npm run android:keystore
npm run android:apk:release
```

راجع `ANDROID_PHASE4.md` لخطوات بناء وتنزيل ملف `APK` من GitHub Actions بدون تثبيت Android Studio.
